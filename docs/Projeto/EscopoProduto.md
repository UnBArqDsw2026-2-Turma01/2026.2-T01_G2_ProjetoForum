# Escopo do Produto

## 1. Visão do Produto

O G2 — Fórum é uma plataforma de discussão e compartilhamento
de conhecimento, desenvolvida no âmbito da disciplina de Arquitetura
e Desenho de Software da FCTE-UnB.

A proposta é criar um ambiente que permita aos usuários publicar
discussões, compartilhar conhecimentos, responder a outros usuários
e acompanhar conteúdos de seu interesse.

O projeto possui como foco o Design Centrado no Usuário (DCU) e a
Usabilidade/Experiência do Usuário (UX), buscando construir uma
interface intuitiva, acessível e adequada às necessidades dos
usuários.

## 2. Público-Alvo

- Estudantes;
- Professores;
- Pessoas interessadas em compartilhar conhecimento;
- Usuários que procuram respostas para dúvidas específicas.

## 3. Funcionalidades Principais

- Cadastro e autenticação de usuários;
- Criação de publicações;
- Visualização de discussões;
- Respostas às publicações;
- Interação com conteúdos;
- Busca de discussões;
- Organização por categorias ou assuntos;
- Perfil do usuário;
- Sistema de avaliação/interação das publicações.

## 4. Objetivos

- Facilitar o compartilhamento de conhecimento;
- Permitir discussões organizadas;
- Facilitar a descoberta de conteúdos;
- Proporcionar uma experiência de uso simples e intuitiva;
- Aplicar princípios de Design Centrado no Usuário;
- Avaliar aspectos de Usabilidade e UX durante o desenvolvimento.

## 5. Fora do Escopo

Nesta primeira entrega, não fazem parte do escopo:

- Sistema avançado de recomendação;
- Monetização da plataforma;
- Aplicativo mobile nativo;
- Integrações externas complexas;
- Sistemas avançados de moderação automatizada.

## 6. Restrições

O projeto será desenvolvido no contexto acadêmico da disciplina
de Arquitetura e Desenho de Software da FCTE-UnB, considerando o
tempo, recursos e objetivos definidos para a entrega.

## 7. Critérios de Sucesso

O produto será considerado adequado quando:

- Os usuários conseguirem realizar as principais tarefas de forma
  intuitiva;
- A navegação apresentar baixa complexidade;
- As funcionalidades principais forem facilmente identificáveis;
- Os usuários conseguirem criar e consultar discussões;
- Os princípios de DCU e Usabilidade forem evidenciados no projeto.
