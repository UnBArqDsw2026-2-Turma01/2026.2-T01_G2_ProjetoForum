# Atas

Esta pasta contém as atas das reuniões realizadas pela equipe do G2 - Fórum durante o desenvolvimento do projeto na disciplina de Arquitetura e Desenho de Software (FGA0208).

## Sobre

As atas têm como objetivo registrar as principais discussões, decisões e encaminhamentos realizados durante as reuniões da equipe.

Os registros ajudam no acompanhamento das atividades, na organização das responsabilidades e na manutenção do histórico das decisões tomadas durante o desenvolvimento do projeto.

## Informações registradas

Cada ata pode apresentar:

* Data da reunião;
* Participantes;
* Pautas discutidas;
* Decisões tomadas;
* Atividades definidas;
* Responsáveis pelas atividades;
* Pendências e encaminhamentos.

## Organização

As atas são organizadas de acordo com cada reunião realizada pela equipe, mantendo o histórico das discussões e decisões do projeto.

Novas atas devem ser adicionadas à medida que novas reuniões forem realizadas.
