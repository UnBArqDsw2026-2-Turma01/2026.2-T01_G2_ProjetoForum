## 1. Introdução

Esta análise de engenharia reversa foi realizada a partir da observação da tela inicial do site **TabNews** (tabnews.com.br), restrita à visão de um usuário não autenticado. O foco desta análise compreende a barra de navegação superior e os fluxos de listagem de conteúdo das abas principais: **Relevantes** e **Recentes**.

Esta análise tem como base a interface ta tela inicial. A exploração de postagens individuais e seus detalhes internos estão fora do escopo deste documento.

Os requisitos foram descritos utilizando a estrutura **"O sistema deve..."**, mantendo cada requisito claro, específico e verificável. Regras e condições foram registradas separadamente como regras de negócio.

---

## 2. Barra de Navegação Superior - Header

A barra de navegação superior é o componente global presente em todas as visões da tela inicial, fornecendo acesso aos principais diretórios e ações de controle da plataforma.

**Elementos observados**
- Logotipo TabNews (link para a página inicial).
- Links de navegação principal: **Relevantes** e **Recentes**.
- Ícone de Busca (lupa).
- Ícone de Sol (alternância de tema claro/escuro).
- Links de autenticação: Login e Cadastrar.

**Requisitos funcionais identificados**

| ID | Requisito |
|---|---|
| RF01 | O sistema deve exibir um cabeçalho global contendo a marca da plataforma e os principais links de navegação. |
| RF02 | O sistema deve permitir a navegação para a aba **Relevantes** a partir do cabeçalho. |
| RF03 | O sistema deve permitir a navegação para a aba **Recentes** a partir do cabeçalho. |
| RF04 | O sistema deve disponibilizar uma funcionalidade de busca no cabeçalho. |
| RF05 | O sistema deve permitir que o usuário alterne o tema de exibição da interface. |
| RF06 | O sistema deve disponibilizar acesso aos fluxos de autenticação (Login) e criação de conta (Cadastrar) para usuários não autenticados. |

---

## 3. Aba Relevantes

A aba **Relevantes** atua como a visão principal ou padrão da plataforma. Ela apresenta uma lista ranqueada das publicações com maior engajamento ou importância atual.

**Elementos e Fluxo observados**
Acessar a raiz do site seleciona ativamente a aba **Relevantes**, indicado por um sublinhado na navegação. O conteúdo exibe:
1. Uma publicação fixada ou destacada no topo, caracterizada por texto na cor verde, informando o título e o autor contribuinte.
2. Uma lista numerada de postagens orgânicas.
3. Para cada postagem, são exibidos os metadados: Título da publicação, quantidade de *tabcoins*, quantidade de comentários, nome de usuário do autor e o tempo decorrido desde a publicação.

**Requisitos funcionais identificados**

| ID | Requisito |
|---|---|
| RF07 | O sistema deve exibir, na visão **Relevantes**, uma lista ordenada e numerada de publicações. |
| RF08 | O sistema deve permitir a exibição de conteúdos destacados ou patrocinados no topo da lista, diferenciados visualmente. |
| RF09 | O sistema deve exibir o título de cada publicação na lista. |
| RF10 | O sistema deve exibir a pontuação da publicação representado pela quantidade de *tabcoins*. |
| RF11 | O sistema deve exibir a quantidade de comentários de cada publicação. |
| RF12 | O sistema deve exibir o nome de usuário do autor da publicação. |
| RF13 | O sistema deve exibir o tempo relativo decorrido desde a data da publicação. |

---

## 4. Aba Recentes

A aba **Recentes** foca na exibição cronológica das atualizações da plataforma, oferecendo filtros adicionais para segmentar o tipo de conteúdo visualizado.

**Elementos e Fluxo observados**
Ao navegar para a aba **Recentes**, uma sub-barra de navegação aparece abaixo do cabeçalho principal, contendo os filtros: "Publicações", "Comentários", "Classificados" e "Todos". A aba ativa na imagem de referência é "Publicações". 
Assim como na parte anterior (Relevantes), existe um conteúdo destacado no topo e a listagem numerada das postagens mais recentes, exibindo os mesmos metadados, como título, tabcoins, comentários, autor e tempo relativo.

**Requisitos funcionais identificados**

| ID | Requisito |
|---|---|
| RF14 | O sistema deve exibir, na visão **Recentes**, uma lista ordenada cronologicamente das interações mais novas da plataforma. |
| RF15 | O sistema deve disponibilizar um submenu de filtros dentro da aba **Recentes** com as opções: "Publicações", "Comentários", "Classificados" e "Todos". |
| RF16 | O sistema deve sinalizar visualmente a origem externa de um conteúdo quando aplicável. |

---

## 5. Regras de negócio identificadas

| ID | Regra de negócio |
|---|---|
| RN01 | A ordenação padrão na aba **Relevantes** depende de um algoritmo interno de ranqueamento baseado no engajamento da postagem, ao passo que a aba **Recentes** obedece a uma ordem estritamente cronológica. |
| RN02 | As listas de conteúdos devem ser numeradas sequencialmente para facilitar a identificação da posição da publicação na listagem. |
| RN03 | Métricas de engajamento através de comentários e da avaliação da postagem, tais métricas devem ser exibidas publicamente para todos os usuários, mesmo os não autenticados, em ambas as abas principais. |

---

## 6. Observações encontradas

- A interface possui uma abordagem fortemente voltada para o texto, mais especificamente markdown, assemelhando-se a fóruns clássicos e agregadores de notícias como reddit, focando na densidade de informação em detrimento de mídias pesadas na tela inicial.
- O termo "tabcoins" é utilizado como a nomenclatura exclusiva da plataforma para o sistema de pontuação semelhante aos upvotes e downvotes do reddit.

---

## 7. Limitações da análise

- A análise baseou-se inteiramente na interpretação de capturas de tela estáticas da interface. Funcionalidades dinâmicas, como paginação, comportamento do scroll infinito ou responsividade em dispositivos móveis, não puderam ser verificadas.
