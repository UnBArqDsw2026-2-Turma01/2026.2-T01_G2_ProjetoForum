A SubEquipe_02 trabalha com os três focos definidos para a Entrega 1,
mantendo como contexto o projeto **Fórum TabNews**, uma plataforma de
discussão e compartilhamento de conhecimento inspirada no **TabNews**.

| Foco | Atividade | Definição | Participante |
| :--- | :--- | :--- | :--- |

| **FOCO_02** | Engenharia Reversa | Análise do **TabNews** como plataforma de referência para identificação de características, funcionalidades e fluxos relevantes. | Pablo |

### 2.1. Relação entre os artefatos

O **Rich Picture** será utilizado para representar visualmente o contexto
e os elementos relacionados à tela **Inicial** do Fórum TabNews.

A partir desse contexto, o **NFR Framework** será utilizado para representar
o atributo de qualidade **Usabilidade**, identificando softgoals,
decomposições e operacionalizações relacionadas à experiência do usuário
durante o acesso à plataforma.

No **FOCO_02**, a Engenharia Reversa terá como referência o **TabNews**,
buscando compreender características e fluxos de uma plataforma de fórum
existente e utilizar os achados como base para a modelagem BPMN.

## 8. Referência do Projeto

O **Fórum TabNews.** é uma plataforma de discussão e compartilhamento de
conhecimento desenvolvida para a disciplina de Arquitetura e Desenho de
Software da FCTE-UnB.

Como referência para a análise de plataformas existentes, a equipe utiliza
o **TabNews**, considerando aspectos relacionados à publicação de conteúdos,
interação entre usuários, organização das discussões, navegação e
experiência de uso.

A análise do TabNews possui caráter de **Engenharia Reversa** e não tem como
objetivo reproduzir integralmente a plataforma. Os conhecimentos obtidos
serão utilizados para apoiar as decisões de desenho e arquitetura do
**Fórum TabNews.**.
