# 1.1.2. Modelagem BPMN

## Notação BPMN

A *Business Process Model and Notation* (BPMN) é uma notação padronizada
utilizada para a modelagem de processos, permitindo representar
graficamente as atividades, eventos, decisões e interações existentes em
um determinado fluxo.

A notação é mantida pela *Object Management Group* (OMG) e busca fornecer
uma representação compreensível tanto para pessoas envolvidas na definição
dos processos quanto para profissionais responsáveis pelo desenvolvimento
e implementação de sistemas.

A BPMN utiliza elementos gráficos padronizados para representar o fluxo de
um processo, facilitando a compreensão das atividades realizadas, dos
participantes envolvidos, das decisões tomadas e das informações
manipuladas durante a execução.

No contexto do projeto **Fórum**, a BPMN será utilizada como parte da
atividade de **Engenharia Reversa**, tendo o **TabNews** como plataforma de
referência.

A modelagem busca representar processos identificados durante a análise da
plataforma de referência, permitindo compreender como determinadas
funcionalidades são organizadas e como ocorre a interação entre o usuário
e o sistema.

## Principais Abstrações

A modelagem BPMN utiliza diferentes elementos para representar os processos
e suas interações. Entre os principais elementos utilizados estão:

- **Pool:** representa um participante ou entidade envolvida no processo,
  podendo representar uma organização, sistema ou participante externo.

- **Lane:** subdivide uma Pool para organizar atividades de acordo com
  diferentes participantes, responsabilidades ou papéis.

- **Eventos:** representam acontecimentos que iniciam, interrompem,
  influenciam ou encerram um processo.

- **Atividades:** representam ações executadas durante o processo, podendo
  corresponder a ações realizadas pelo usuário ou pelo sistema.

- **Subprocessos:** representam um conjunto de atividades relacionadas que
  fazem parte de um processo maior.

- **Gateways:** representam pontos de decisão, ramificação ou sincronização
  do fluxo.

- **Fluxo de Sequência:** representa a ordem em que as atividades e eventos
  são executados dentro de um processo.

- **Fluxo de Mensagem:** representa a comunicação entre participantes
  distintos de um processo.

- **Objetos de Dados:** representam informações utilizadas ou produzidas
  durante a execução de uma atividade.

Esses elementos permitem representar o comportamento de um processo de
forma visual e estruturada.

## Processo Selecionado para Modelagem

A modelagem BPMN será realizada a partir dos processos identificados durante
a **Engenharia Reversa do TabNews**.

O processo selecionado para a modelagem deve apresentar um fluxo
significativo da plataforma, permitindo representar as principais
interações entre usuário e sistema.

Para esta etapa, será considerado o seguinte processo:

### Fluxo de Login

O fluxo de Login representa o processo de autenticação de um usuário na
plataforma.

O processo contempla, de forma geral:

1. acesso à tela de Login;
2. preenchimento das credenciais;
3. envio das informações;
4. validação das credenciais;
5. tomada de decisão de acordo com o resultado da autenticação;
6. apresentação do resultado ao usuário;
7. acesso à plataforma quando a autenticação é realizada com sucesso.

A modelagem BPMN busca representar esse fluxo de maneira estruturada,
evidenciando as atividades realizadas pelo usuário, as ações executadas
pelo sistema e os pontos de decisão existentes no processo.

## Engenharia Reversa e BPMN

A Modelagem BPMN está diretamente relacionada ao processo de Engenharia
Reversa realizado pela equipe.

Inicialmente, a equipe analisou o comportamento e as funcionalidades
disponibilizadas pelo **TabNews**, utilizado como referência para o domínio
de fóruns e compartilhamento de conhecimento.

A partir dessa análise, foram identificadas as principais etapas do fluxo
selecionado e suas respectivas interações.

Essas informações foram utilizadas como insumo para a construção do modelo
BPMN, buscando representar o processo observado de forma padronizada.

Dessa maneira, a BPMN não representa apenas uma funcionalidade isolada,
mas uma abstração do processo identificado durante a análise da plataforma
de referência.

### Descrição do fluxo

O processo é iniciado quando o usuário acessa a funcionalidade de Login.

Em seguida, o usuário fornece suas credenciais e solicita a autenticação.
O sistema recebe as informações fornecidas e realiza a validação dos dados.

Após a validação, ocorre uma decisão:

- caso as credenciais sejam válidas, o sistema permite o acesso à
  plataforma;
- caso as credenciais sejam inválidas, o sistema informa o problema ao
  usuário e permite uma nova tentativa.

O fluxo é encerrado após o acesso bem-sucedido à plataforma ou após a
interação definida para o tratamento da tentativa de autenticação.

## Considerações Finais

A utilização da BPMN permite representar de maneira padronizada o processo
identificado durante a Engenharia Reversa do **TabNews**.

A modelagem do fluxo de Login possibilita visualizar as principais
atividades realizadas pelo usuário, as ações executadas pelo sistema e os
pontos de decisão existentes durante o processo de autenticação.

Além disso, o modelo contribui para a compreensão do comportamento da
plataforma de referência e serve como apoio para as decisões relacionadas
ao desenho da solução proposta pelo projeto.

O modelo poderá ser refinado conforme novos aspectos do fluxo forem
identificados durante a evolução da Engenharia Reversa e das demais
atividades da Entrega 1.
