# Sketch

1. Introdução:

Sketch (Esboço) é uma etapa do Design Sprint dedicada à geração e representação visual de possíveis soluções para o problema identificado. Nessa fase, cada participante desenvolve individualmente suas ideias por meio de esboços, buscando apresentar de forma clara como sua solução poderia funcionar. O objetivo não é criar um desenho perfeito ou um produto final, mas explorar diferentes alternativas de maneira rápida e concreta, permitindo que a equipe posteriormente avalie e selecione as ideias mais promissoras.
