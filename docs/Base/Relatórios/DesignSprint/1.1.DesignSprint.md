# 1.1 Módulo Design Sprint

## O que é Design Sprint?

Design Sprint é uma metodologia criada pela Google Ventures para resolver problemas e desenvolver soluções de forma rápida e colaborativa. Ela reúne uma equipe para entender um problema, criar e selecionar ideias, desenvolver um protótipo e, por fim, testá-lo com usuários reais. Tradicionalmente, o processo é realizado em cinco dias, permitindo validar uma ideia antes de investir muito tempo e recursos em seu desenvolvimento.
