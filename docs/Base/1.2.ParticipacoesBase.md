## Observação sobre os comprobatórios

Os comprobatórios devem apresentar evidências claras da participação de cada integrante, podendo incluir:

* Links para os artefatos produzidos;
* Links para Issues relacionadas à atividade;
* Links para Pull Requests;
* Links para commits individuais;
* Links para discussões e decisões realizadas pela equipe;
* Outros registros de versionamento que permitam identificar a contribuição do integrante.
